BD Location API

বাংলাদেশের প্রশাসনিক অবস্থান ডেটা সহজ RESTful API ব্যবহার করুন। Vercel-এ হোস্ট করা JSON ফাইল থেকে অ্যাক্সেস করুন। কোনো অথেনটিকেশন প্রয়োজন নেই।

https://bdlocation.vercel.app/

GET /divisions.json

সকল বিভাগের তালিকা (Retrieve all divisions)।

https://bdlocation.vercel.app/divisions.json
প্রতিক্রিয়া (Response): [ { "id": "1", "name": "Chattagram", "bn_name": "চট্টগ্রাম" } ]

GET /upazilas.json

সকল উপজেলার তালিকা (Retrieve all upazilas) - district_id দিয়ে ফিল্টার করুন।

https://bdlocation.vercel.app/upazilas.json
প্রতিক্রিয়া (Response): [ { "id": "7", "district_id": "1", "name": "Homna", "bn_name": "হোমনা", "url": "homna.comilla.gov.bd" } ]

GET /districts.json

সকল জেলার তালিকা (Retrieve all districts) - division_id দিয়ে ফিল্টার করুন।

https://bdlocation.vercel.app/districts.json
প্রতিক্রিয়া (Response): [ { "id": "1", "division_id": "1", "name": "Comilla", "bn_name": "কুমিল্লা", "lat": "23.4682747", "lon": "91.1788135", "url": "www.comilla.gov.bd" } ]

GET /unions.json

সকল ইউনিয়নের তালিকা (Retrieve all unions) - upazila_id দিয়ে ফিল্টার করুন।

https://bdlocation.vercel.app/unions.json
প্রতিক্রিয়া (Response): [ { "id": "1", "upazila_id": "7", "name": "Subil", "bn_name": "সুবিল", "url": "subilup.comilla.gov.bd" } ]

API ব্যবহারের নিয়ম (How to Use the API)

  1. ডেটা লোড করুন: JavaScript-এর fetch() বা Axios ব্যবহার করে JSON এন্ডপয়েন্ট GET করুন।
  2. হায়ারার্কিক্যাল ফিল্টার: সকল ডেটা একবার লোড করে (ফাইল ছোট) ID দিয়ে ক্লায়েন্ট-সাইড ফিল্টার করুন।
  3. JavaScript উদাহরণ:
// বিভাগ লোড করুন (Load divisions) fetch('https://bdlocation.vercel.app/divisions.json') .then(res => res.json()) .then(data => console.log(data)); // ড্রপডাউনে ব্যবহার করুন // অন্যান্যগুলোর জন্যও একইভাবে, তারপর ফিল্টার: // const districts = allDistricts.filter(d => d.division_id === selectedDivisionId);

রেট লিমিট: Vercel-এ হোস্ট করা বলে ভাল পারফরম্যান্স পাওয়া যাবে। প্রোডাকশনে নিজের সার্ভার বা CDN ব্যবহার করুন।
