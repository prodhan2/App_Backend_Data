বাংলাদেশের বিভাগ, জেলা, উপজেলা এবং ইউনিয়ন পর্যায়ে অবস্থান অনুসন্ধান করুন। ডেটা সোর্স: GitHub Repo।

নির্বাচিত অবস্থানের বিবরণ (Selected Location Preview)

BD Location API

বাংলাদেশের প্রশাসনিক অবস্থান ডেটা সহজ RESTful API ব্যবহার করুন। GitHub-এ হোস্টেড JSON ফাইল থেকে অ্যাক্সেস করুন। কোনো অথেনটিকেশন প্রয়োজন নেই। বেস URL: https://raw.githubusercontent.com/prodhan2/App_Backend_Data/main/RUCSEHUB/LocationApiOFBD/

API ব্যবহারের নিয়ম (How to Use the API)

  1. ডেটা লোড করুন: JavaScript-এর fetch() বা Axios ব্যবহার করে JSON এন্ডপয়েন্ট GET করুন।
  2. হায়ারার্কিক্যাল ফিল্টার: সকল ডেটা একবার লোড করে (ফাইল ছোট) ID দিয়ে ক্লায়েন্ট-সাইড ফিল্টার করুন।
  3. JavaScript উদাহরণ:
// বিভাগ লোড করুন (Load divisions) fetch('https://raw.githubusercontent.com/prodhan2/App_Backend_Data/main/RUCSEHUB/LocationApiOFBD/divisions.json') .then(res => res.json()) .then(data => console.log(data)); // ড্রপডাউনে ব্যবহার করুন // অন্যান্যগুলোর জন্যও একইভাবে, তারপর ফিল্টার: // const districts = allDistricts.filter(d => d.division_id === selectedDivisionId);

রেট লিমিট: GitHub অনথেনটিকেটেড ~60 রিকোয়েস্ট/ঘণ্টা। প্রোডাকশনে নিজের সার্ভার বা CDN ব্যবহার করুন।
